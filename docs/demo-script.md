# Three-minute demonstration

1. Open a fresh browser and choose Try the sample course. Explain the three lectures and two worksheets are original published material.
2. Ask how recursion consumes a list. Open a citation, read the supporting quote, and compare the physical PDF page in the preview.
3. Ask a follow-up using the previous answer, then ask the exam date. Explain why missing course evidence should produce an explicit refusal.
4. Select one lecture. Generate a summary, inspect its coverage, and download Markdown.
5. Create a quiz, answer all five questions, submit, and inspect the application-calculated score with source-backed explanations. Export the review.
6. Create ten flashcards. Flip a card and export TSV for Anki.
7. Upload a small text PDF, explain temporary processing and Groq disclosure, inspect its status, then delete the private session.

The original project year is 2025. Describe the public application as an expanded release, and report only its separately measured results.
